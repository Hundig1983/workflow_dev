## Findings from this session

### Fixed and merged to `~/.claude/skills` main (`a441715`)
- **The label taxonomy never materialised on any fresh repo.** Two rules cancelled out: Step 4 listed
  `type:`/`area:`/`prio:` as *fallback defaults*, while the `silent_label_creation` anti-pattern forbade
  creating them. Silent no-op — issue #2 published with only `enhancement`. Now `create-issue`
  **provisions the resolved taxonomy before publishing** (additive, idempotent, one code path for
  `gh`/`glab` — diff existing names rather than `--force`, which `glab` lacks), and every issue must
  carry one `type:`, one `prio:` (default P2), and at least one `area:`. New
  `create-issue/references/label-taxonomy.md`; `silent_label_creation` →
  `inventing_labels_outside_the_taxonomy`.
- **A slice PR left no path to closure.** `Refs #N` correctly keeps the issue open, but the *reason*
  lived only in the PR body and console output, both invisible after merge. `phase-11-pr.md` step 5.5
  now posts a comment recording what shipped and what remains.

### Open findings — NOT fixed
**Tier 1 — structural**
- **Post-flight constitution verification is a no-op for Forge-native manifests.** Confirmed twice now.
  The manifest carries only `citation` (9) and `text-presence` (9) predicates and **zero** code-level
  ones, so `issue-orchestrator` Phase 8 step 5 has nothing to run. Coverage of 100% means "the proposal
  used the right words", never "the code obeys the constitution". Both ends of the loop are open.
- **Decisions made in a change's `design.md` never reach the constitution.** The walking skeleton also
  decided opaque-sessions-over-JWT and the atomic-registration rule; neither is in a canonical source, so
  neither was visible to the derive. Only Fastify surfaced, and only because task 8.4 hand-wrote it back
  into `ARCHITECTURE.md`. Nothing makes that write-back systematic.
- **Nothing verifies the environment can run what it dispatches.** Triage, scoring, guardrails, claim and
  dispatch all completed before anyone discovered there was no database and no container runtime.

**Tier 2 — friction**
- **`jq` default formatting destroys a compact manifest.** Regenerating with `jq` expanded the manifest
  219 → 701 lines and produced a 684-line diff for a 19-line semantic change. Caught and reverted to
  surgical edits. `step-04a-derive.md` never warns about preserving formatting.
- **`create-issue`'s Spec Package block prescribes links that are dead in issue bodies.** Relative links
  don't resolve from a GitHub issue regardless of tracking. Worked around with commit-SHA permalinks.
- **`AskUserQuestion` caps at 4 options** while `spec-creator`'s scope-tag prompt wants a 17-item grid.
- **`orchestrate-constitution` never links an issue** unless `--issue=N` is passed, so governance PRs are
  orphaned from the tracker (PR #5 has no issue keyword).
- Minor: `phase-11-pr.md:35` says GitHub→`Fixes`, `pr-template.md:34` hardcodes `Closes`. Both work.
- Minor: manifest `candidates[]` uses a different shape from `articles[]` — a consumer reusing the
  article projection renders blanks.
